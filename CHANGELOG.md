# Changelog

All notable changes to `affinity-health-sdk` are documented here. This project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html); before 1.0, a minor version can break.

## Unreleased

## 0.4.0 - 2026-10-31

This version is generated by [Fern](https://buildwithfern.com) from API version `2026-10-28`. It
replaces the whole previous interface.

### Changed

- Create the client with `Affinity(token="sk_test_...")`, or `AsyncAffinity(token=...)` for
  asyncio. `token` is a keyword argument. `base_url`, `timeout`, `max_retries` and
  `affinity_version` are optional keyword arguments.
- Methods take keyword arguments in snake_case, and the resource ID first:
  `client.orders.get(order_id)`, `client.orders.cancel(order_id, idempotency_key=...)`.
- Every write requires `idempotency_key`; the SDK no longer generates one. Save the key with the
  reviewed request and send the same key to retry.
- List methods return a pager. Iterating it reads every page; `page.items` is one page.
- Errors are `ApiError` subclasses named by status, such as `UnprocessableEntityError`, whose
  `body.issues` names each refused field.
- Retries default to 2, for 408, 409, 429 and 5xx responses and failed connections, and wait for
  `Retry-After`. They send the same idempotency key. The timeout stays 60 seconds.
- Send API version `2026-10-28` by default.

### Added

- `account.get`, `feedback.create`, `medications.list` and `get`, `orders.create`, `list`, `get`
  and `cancel`, `practices.create`, `list`, `get` and `update`, and `webhooks.list`, `create`,
  `update`, `remove` and `resend_failed`: the 17 operations of API `2026-10-28`.
- `orders.create` creates, signs and sends an order in one request, with the patient and
  prescriber inline.
- `docs/reference.md`, the reference for every method.
- A README example that verifies webhook signatures with the standard library.

### Removed

- Patients, catalog, team, locations, signing and submission methods, practice-scoped clients and
  the hand-written facade. API version `2026-10-28` does not have them.

## 0.3.0 - 2026-10-07

### Changed

- Regenerate from the deployed API contract used by TypeScript SDK 1.16.0.
- Use https://api.affinityrx.com and API version 2026-09-28.
- Add presentation-price reads and remove customer purchase-price writes.

- Use direct API-key constructors, short nested resource methods, and separate request options across all 73 API operations.
- Resolve practice keys automatically and support immutable scoped clients or per-request practice context.
- Generate keys for routine writes, including patient deletion; require persisted keys for consequential order actions.
- Add lazy pagination iterators and consistent API error metadata.
- Accept patient status `archived` as an alias for the API's `inactive` status.
- Default to API `2026-09-28`, a 60-second timeout, and no automatic retries.
- Verify the language guide examples against the implemented client.

## 0.1.0 - 2026-09-28

- Initial Python SDK preview for Affinity API version `2026-09-28`.
- Generated resource clients, request and response types, and transport verification.
