# Affinity Python SDK

**No Python SDK has been released.** This repository is a placeholder and contains no installable PyPI or client source. Earlier examples here named packages and methods that do not exist; do not use those instructions.

For a Python integration today, generate a client from the [public OpenAPI document](https://api.joinaffinityai.com/v1/openapi.json). Send the supported `Affinity-Version: 2026-08-11` header and keep API keys in trusted server code. The [Affinity API documentation](https://docs.joinaffinityai.com/) describes the current endpoints and authentication rules.

The maintained official SDK is [TypeScript](https://github.com/affinity-health/affinity-typescript). Check the [SDK guide](https://docs.joinaffinityai.com/guides/reference/sdks/) before assuming another language package is available.
